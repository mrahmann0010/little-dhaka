# Little Dhaka

Website for a South Asian restaurant, built with React 19, Vite, React Router and Tailwind CSS.

## Scripts

```bash
npm install      # install dependencies
npm run dev      # dev server on http://localhost:3000 (npm start also works)
npm run build    # production build into dist/
npm run preview  # serve the production build locally
```

Static files (images, favicon, manifest) live in `public/` and are served from `/`.

See [docs/ABOUT.md](docs/ABOUT.md) for the project overview and [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md) for design tokens.
